# Security Policy

## Supported Versions

We take the security of `2-Power-Max-Brightness` seriously. Below are the versions that are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `2-Power-Max-Brightness`, please report it responsibly. **Do not disclose security-related issues publicly until they have been addressed and a patch has been released.**

### How to Report

To report a vulnerability, please reach out via one of the following methods:

* **Private Vulnerability Reporting:** Use GitHub's built-in [Private Vulnerability Reporting](https://github.com/Jamagoze/2-Power-Max-Brightness/security/advisories/new) feature on the repository.
* **Direct Contact:** Alternatively, you can reach out directly to the repository maintainer through their GitHub profile or associated communication channels.

Please include as much detail as possible to help us reproduce and resolve the issue quickly, including:
* A description of the vulnerability and its potential impact.
* Steps or a proof-of-concept (PoC) to reproduce the issue.
* Any potential mitigations you have already identified.

### What to Expect

* **Acknowledgment:** You will receive an initial response acknowledging receipt of your report within 48–72 hours.
* **Investigation:** The maintainer will investigate the issue, verify its validity, and assess its severity.
* **Resolution & Disclosure:** Once a fix is prepared, a patch will be released, and proper credit will be given to the reporter (unless requested otherwise) in the release notes and security advisory.

Thank you for helping keep `2-Power-Max-Brightness` secure!
