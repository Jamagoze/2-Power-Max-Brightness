# Contributing to 2-Power-Max-Brightness

Thank you for your interest in contributing to **2-Power-Max-Brightness**! We welcome contributions from developers, modders, and testers.

Please take a moment to review these guidelines before submitting code, scripts, or issues.

---

## Code of Conduct

Maintain a respectful, open, and constructive environment. Focus on clear feedback, objective code reviews, and collaborating to improve performance and stability.

---

## How Can You Contribute?

### 1. Reporting Bugs
If you run into issues on specific devices, ROMs, or system builds:
* Check existing [Issues](https://github.com/Jamagoze/2-Power-Max-Brightness/issues) to avoid duplicates.
* Open a new issue with a clear title and details:
  * **Device & SoC:** (e.g., Xiaomi Redmi Pad SE / Snapdragon 680)
  * **OS / Firmware Version:** (e.g., HyperOS, Android 14)
  * **Root Method & Version:** (e.g., Magisk v30.7, KernelSU)
  * **Steps to Reproduce:** Exact steps or environment setups.
  * **Logs:** Relevant terminal output, `logcat`, or `dmesg` logs if available.

### 2. Suggesting Enhancements
Feature requests or device compatibility updates are welcome!
* Provide a clear description of the feature or parameter optimization.
* Explain the practical benefit (e.g., power efficiency, reduced latency, lower thermal output).
